# カラーパレット (wfai)

Windows Forms (.NET 10) で作成した、シンプルなカラーパレットアプリです。
色見本のプレビュー、HSL トラックバーによる調整、定義済みスウォッチからの選択、
`#RRGGBB` カラーコードのコピーができます。

> **Note:** このコードは **Cline (VSCode 拡張) の無料枠 / Step 5 preview** を用いて生成されました。

## 機能

| 機能 | 説明 |
|------|------|
| 色見本プレビュー | 選択中の色を大きなパネルに表示 |
| HSL トラックバー | 色相 (H: 0–360)・彩度 (S: 0–100)・明度 (L: 0–100) をスライダーでリアルタイム調整 |
| スウォッチ一覧 | マテリアルカラー 19 色をクリックで即座に適用 |
| カラーピッカー | 「色を選ぶ」から Windows 標準の `ColorDialog` を起動 |
| カラーコード表示・コピー | `#RRGGBB` を表示し、「コピー」でクリップボードへ |

HSL と RGB の相互変換は標準ライブラリのみで自前実装しています
(`RgbToHsl` / `HslToRgb` / `HueToRgb`)。

## 動作環境

- .NET 10 (`net10.0-windows`)
- Windows Forms
- OS: Windows

## 実行方法

```powershell
dotnet run
```

## ビルド

```powershell
dotnet build
```

## 使い方

1. **スウォッチをクリック** — 左の一覧から色を選ぶと、色見本・カラーコード・トラックバーが連動して更新されます。
2. **H / S / L トラックバーをドラッグ** — 微調整。スライダー操作に応じて色がリアルタイムに変化します。
3. **「色を選ぶ」** — より細かい色はカラーピッカーから指定できます。
4. **「コピー」** — 現在の `#RRGGBB` をクリップボードにコピーします。

## 設計メモ

- **フィードバックループ対策**: スウォッチ等で色を適用する際、トラックバーを更新すると
  その `Scroll` イベントで再計算が走り無限ループになりがちです。`_updating` フラグの
  ガード処理で、プログラム側からの更新時はイベントを無視する構成にしています。
- **値のクランプ**: `TrackBar.Value` は範囲外を設定すると例外になるため、
  RGB↔HSL のラウンドトリップで生じる微小なずれを `Clamp()` で丸めています。
